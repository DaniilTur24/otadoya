# Как вести табель посещаемости

Кому: бухгалтер, администратор, заведующая (только по своим аптекам). Применимо к четырём табельным типам сотрудников (уборщица, офис, заведующая-не-торгует, менеджер), а также к продавцу или заведующей-торгует с включённой галочкой «Пятидневка по табелю» (на `/employees` для продавца, на `/users` для заведующей) и к типу «Суточник / пятидневка (фикс)» (см. [reference-employee-types.md](reference-employee-types.md#сводная-таблица) — почему именно эти).

## Шаги

1. Откройте `/attendance`. Выберите **месяц** и **год** в шапке (стрелки «← Пред.» / «След. →» переключают на соседний месяц).
2. В таблице по строкам — сотрудники табельных типов, по столбцам — дни месяца (выходные подсвечены серым). Если сотрудник привязан к нескольким аптекам — рядом с его именем появится выпадающий список, чтобы выбрать, к какой аптеке относится отметка.
3. **Отметить один день**: кликните по ячейке нужного дня — появится зелёная галочка.
4. **Отметить диапазон сразу**: кликните на первый день, затем Shift+клик на последний (или используйте стрелки + Shift+стрелка для выделения с клавиатуры) — выделится диапазон, появятся кнопки **«Отметить»**/**«Снять»** для всего выделения разом.
5. Снять отметку — повторный клик по уже отмеченной ячейке (или «Снять» для диапазона).

Столбец «Итого» справа показывает количество отмеченных дней — это и есть `attendanceShiftsCount`, который напрямую участвует в формуле зарплаты этого сотрудника.

## Клавиатурная навигация

Таблица поддерживает табличную навигацию: стрелки перемещают активную ячейку без изменения отметок, Enter/Space переключают отметку текущей ячейки, Shift+стрелка расширяет диапазон выделения, Esc сбрасывает выделение.

## Типичные ошибки

- «Этому типу сотрудника нельзя отметить табель — он учитывается через смену в записи выручки» — попытка отметить табель продавцу или торгующей заведующей (без «Пятидневки» и не «Суточник / пятидневка (фикс)»). Их рабочие дни вносятся через [запись дневной выручки](howto-enter-daily-revenue.md), а не здесь.
- «На эту дату у сотрудника уже назначена смена в записи выручки — нельзя также отметить табель» — для типа «Суточник / пятидневка (фикс)»: на одну календарную дату можно либо смену в выручке, либо отметку табеля, не оба сразу.
