# Как настроить премии и рабочий календарь

Кому: администратор (`/settings/*` доступен только `admin`). Эти настройки напрямую влияют на формулы из [reference-salary-formulas.md](reference-salary-formulas.md) — без них часть зарплат посчитается нулевой.

## Рабочий календарь (`/settings/working-calendar`)

Используется для делителя пятидневных смен (`baseSalary / workingDays × отработанные дни`) — для `five_day`-смены продавца и для всех табельных типов (`manager_fixed`, `office`, `pharmacy_manager`).

1. Откройте `/settings/working-calendar`, выберите **год**.
2. Для каждого месяца впишите число рабочих дней в поле справа от названия месяца.
3. Нажмите кнопку сохранения рядом со строкой (или Enter в самом поле) — кнопка на 2 секунды покажет «Сохранено».

Если на месяц не задано число рабочих дней, делитель равен `null`, и пятидневная часть зарплаты для всех затронутых сотрудников за этот месяц считается **нулём** — не забывайте заполнять календарь заранее, в начале месяца.

## Лестничная премия заведующих по аптеке (`/settings/pharmacies/[id]`)

Применяется к `manager_fixed` (заведующая без личных продаж), и опционально — к `pharmacy_manager` (если включён `managerPremiumEnabled` у конкретного менеджера, см. [howto-manage-employees.md](howto-manage-employees.md#заведующая-или-менеджер-users)). У `manager_trading` (заведующая, которая торгует) этой премии нет — вместо неё личная премия за выручку смены, как у продавца.

1. Откройте карточку нужной аптеки в настройках.
2. В блоке «Премия заведующих этой аптеки» заполните четыре поля:
   - **Порог выручки для премии (₸)** — с какой месячной выручки аптеки начинает начисляться премия.
   - **Премия за порог (₸)** — базовая сумма при достижении порога.
   - **Шаг выручки (₸)** — на сколько должна вырасти выручка сверх порога для следующей надбавки.
   - **Прибавка премии за шаг (₸)** — сколько добавляется за каждый полный шаг.
3. Сохраните.

Формула: при выручке ≥ порога выдаётся базовая премия, дальше за каждые полных «шаг выручки» сверху добавляется «прибавка за шаг» — лестница накопительная (см. [explanation-salary-design.md](explanation-salary-design.md)). Если поля не заполнены — премия для этой аптеки не начисляется никому.

## Премия офиса по диапазонам выручки (`/settings/office-premium`)

Единая для всей сети таблица: суммарная выручка всех аптек за месяц → фиксированная премия офисному сотруднику. **Не накопительная** — премия берётся из одной строки, в чей диапазон попадает выручка, а не суммируется по предыдущим строкам.

1. Откройте `/settings/office-premium`.
2. Для каждой строки заполните **«От» (₸)**, **«До» (₸, необязательно)** и **«Премия» (₸)**. Последнюю строку можно оставить без «До» — тогда она действует «свыше …» без верхней границы.
3. Кнопкой **«+ Добавить диапазон»** добавляйте новые строки, крестиком — удаляйте.
4. Нажмите **«Сохранить»** — пустые строки (без суммы «От» или «Премия») сохранены не будут, остальные автоматически отсортируются по возрастанию.
