# Как завести и настроить сотрудника

Кому: администратор (создание/редактирование большинства полей — только `admin`), бухгалтер (может заводить и редактировать заведующих/менеджеров на `/users`).

Сначала определите тип — таблица различий в [reference-employee-types.md](reference-employee-types.md). Три типа (заведующая-торгует, заведующая-не-торгует, менеджер) заводятся **только** на `/users` вместе с логином; остальные три (продавец, уборщица, офис) — на `/employees`.

## Продавец, уборщица или офисный сотрудник (`/employees`)

1. Откройте `/employees`, нажмите **«+ Добавить»**.
2. Заполните **имя** и **тип** (Продавец / Уборщица / Офис — другие три типа здесь недоступны).
3. В зависимости от типа появится либо поле **«Оклад (₸)»** (продавец, офис), либо **«Ставка за смену (₸)»** (уборщица) — оба обязательны и должны быть больше нуля.
4. При необходимости заполните **доплату** и **описание доплаты** (фиксированная ежемесячная сумма сверх формулы, действует для любого типа).
5. Отметьте чекбоксами **аптеки**, к которым привязан сотрудник — обязательно хотя бы одна (кроме офиса, для которого привязка к аптеке не нужна — его премия общая для всей сети).
6. Нажмите **«Создать»**.

Редактирование — на `/employees/[id]`: те же поля доступны для правки, плюс блок изменения списка аптек («изменить» рядом со списком тегов).

## Заведующая или менеджер (`/users`)

1. Откройте `/users`, нажмите **«+ Добавить»**.
2. Заполните **username**, **пароль** (минимум 6 символов) и **отображаемое имя**.
3. Выберите **роль**: «Заведующая (торгует)», «Заведующая (не торгует)» или «Менеджер» — под каждым вариантом есть короткое описание формулы зарплаты.
4. Заполните **оклад**, при необходимости **доплату**.
5. Если роль — «Менеджер», появится чекбокс **«Премия включена»** — без него лестничная премия по выручке аптеки для этого менеджера начисляться не будет, даже если у аптеки настроены пороги.
6. Отметьте **аптеки**, к которым привязан аккаунт — это одновременно и зона видимости в системе, и список аптек, по которым считается 10%-доля от бонусов и лестничная премия.
7. Нажмите **«Создать»**.

Это одновременно создаёт логин (`User`) и связанную карточку сотрудника (`Employee`) — они всегда синхронизированы. Имя, оклад, тип и доплату для этих трёх типов нужно менять **только здесь**; на `/employees/[id]` эти поля будут заблокированы с пояснением.

## Деактивация и удаление

- **Деактивировать** — сотрудник остаётся в базе (история сохраняется), но перестаёт попадать в расчёт зарплаты и выпадающие списки для новых записей.
- **Удалить** — доступно только если нет ни одной записи выручки/табеля по этому сотруднику.
- Отвязать сотрудника от аптеки, по которой у него уже есть записи выручки или табеля, нельзя — система заблокирует это с пояснением, сколько записей перестанут учитываться.

## Просмотр зарплаты сотрудника (`/employees/[id]`)

В нижней части страницы — блок расчёта зарплаты с выбором месяца/года/аптеки. Показывает разбивку, специфичную для типа сотрудника (оклад по сменам или по табелю, бонусы, премии, авансы — см. [reference-salary-formulas.md](reference-salary-formulas.md) за точными формулами), плюс таблицы фактических смен/отметок табеля/авансов за выбранный период.
